# JE 谱转调器 · 半音阶口琴

纯静态单页工具：把 JE 谱按「原调 → 目标调」整体升降半音。

**在线使用**：https://ximu0v0.github.io/JE-Modulator/

## 快速开始

```bash
# 本地预览
python -m http.server 5173
# 打开 http://localhost:5173/

```

## 界面说明

- **调性条**：原调 / 目标调双下拉（互换用 `⇄`）、`+1 半音` / `−1 半音` 微调按钮、右侧状态胶囊（如 `1=C → 1=#C · 整体 +1 半音`）
- **双栏谱面**：左侧输入原谱，右侧实时输出结果（只读）
- **信息条**：左栏是**原谱**的最低音 / 最高音，右栏是**转调后**的最低音 / 最高音，右端标注本次音高变化
- **操作区**：示例、清空、复制结果；「高级」折叠区可选临时记号偏好
- **页脚**：固定调模式、转换逻辑、±1 半音按钮的规则说明

## 核心语义（V1.0 · 固定调记谱）

JE 谱的数字对应**绝对音高**，与调性无关：

| 数字 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 音高 | C | D | E | F | G | A | B |

因此「转调」= 整份谱按 **目标调 − 原调** 的半音数整体升降：

- 平移量 `shift = wrapDelta(原调, 目标调)`，最近方向折算到 `[-6, +6]`
- 结果始终以固定调书写，状态胶囊显示 `1=C → 1=#C · 整体 +1 半音`
- `+1 半音` / `−1 半音` 在换算结果上再叠加微调；切换原调、目标调或点「⇄」时归零
- 信息条同时显示原谱音域与转调后音域，便于直接对比半音变化后是否超出乐器音域

### 典型结果

| 原调 → 目标调 | 输入 | 输出 |
| --- | --- | --- |
| 1=C → 1=#C（+1） | `145` | `#1#4#5` |
| 1=C → 1=#C（+1） | `(7)3#4` | `145` |
| 1=C → 1=#C（+1） | `1 2 3` | `#1 #2 4` |
| 1=C → 1=D（+2） | `1 2 3` | `2 3 #4` |
| 1=E → 1=C（−4） | `1 2 3` | `(#5 #6) 1` |
| 1=C → 1=#C（+1） | `#7` | `[#1]` |
| 1=C → 1=C（0） | `[1] [2]` | `[1] [2]`（默认保留分组；高级区开启合并后为 `[1 2]`） |

## JE 谱语法

- `1`–`7` 为音符；`#` / `b` 必须紧贴音符，且仅在**后面紧跟 1–7** 时才算临时记号（否则按普通字符保留）
- `( )` 低八度、`[ ]` 高八度，可嵌套；全角括号等价兼容：`（ ）` = `( )`，`【 】` = `[ ]`（输入可用中文括号，输出统一归一为半角括号）；无括号为中音区
- 空格、换行、`|`、歌词、标点等非音符字符原样保留
- 输出括号策略：按新音高层级重新发放；闭合括号**紧贴在最后一个音符之后**，不会把歌词或小节线包进括号；相邻同层括号**默认不合并**（保留原谱分组），可在「高级」区开启自动合并

## 等音拼写

- 结果落在自然音级 → 直接写数字，不加临时记号
- 落在黑键 → 按「临时记号」选项决定：跟随原谱（默认，原音带 `b` 用降号、否则用升号）/ 全升号 / 全降号
- 只使用单升、单降，不会产生 `##`、`bb`
- 拼写选项位于底部「高级」折叠区

## 算法要点

1. 每个音符换算绝对音高：`绝对半音 = DEGREE_BASE[音级] + 临时记号 + 八度层级 × 12`
2. 加上 `shift` 后拆成「八度进位 `carry = floor(rel / 12)`」与「音级内半音 `rel mod 12`」
3. 新八度层级 = 输入层级 + carry，据此重发括号；同级相邻音符自动合并
4. 音级内半音查表得到书写形式：自然音优先，黑键按拼写偏好选 `#` 或 `b`
5. 每次转调都从**原谱**重算，不做增量修改，避免多次操作累积误差
